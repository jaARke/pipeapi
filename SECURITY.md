# Security policy

## Reporting a vulnerability

Report a vulnerability privately through GitHub: open the repository's Security tab and choose [Report a vulnerability](https://github.com/jaARke/pipeapi/security/advisories/new). Don't open a public issue, discussion or pull request for it.

Include:

- the affected packages and their versions
- the OS and the transport (named pipe, Unix socket or loopback)
- what an attacker needs and what they gain
- steps or code that reproduce it

The maintainer acknowledges the report in the advisory, works on the fix there with you, and credits you when the advisory is published unless you'd rather stay anonymous.

## Supported versions

Security fixes go to the latest release of each package.
